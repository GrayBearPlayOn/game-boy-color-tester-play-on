# PLAY ON — Game Boy Color Tester

**Версия 1.0.0 · Бесплатная программа диагностики Nintendo Game Boy Color**

![Главное меню PLAY ON Game Boy Color Tester](dist/screen-home-4x.png)

## Что проверяет программа

- **Кнопки:** крестовина, A, B, START, SELECT
- **Экран:** цветные заливки, 32-ступенчатые шкалы RGB и серого, сетка, линии, движущийся квадрат
- **Звук:** мелодия, тоны, отдельные звуковые каналы
- **Наушники:** левый и правый каналы
- **Кабель связи Game Link:** обмен данными и обнаружение ошибок
- **Память:** семь банков WRAM, оба банка VRAM, переключение банков
- **Процессор:** обычная и удвоенная скорость
